# SPK-AHP-Ransel-Pendakian
Merancang aplikasi sistem pendukung keputusan ransel pendakian gunung dengan metode analytical hierarchy process yang dapat memberikan rekomendasi ransel pendakian gunung berdasarkan kriteria dan alternatif yang telah ditentukan. Implementasi sistem menggunakan bahasa pemrograman Java, dengan  kode editor Apache NetBeans dan database MySQL. 

Teknologi yang digunakan:
1. Java (Java Swing)
2. JDK 11
3. MySQL
4. XAMPP
5. Apache NetBeans
6. Jaspersoft Studio

Fitur Aplikasi
1. Pengelolaan data alternatif ransel pendakian
2. Pengelolaan data kriteria dan subkriteria
3. Pengolahan matriks perbandingan berpasangan
4. Perhitungan bobot prioritas menggunakan metode AHP
5. Pengujian konsistensi (Consistency Ratio)
6. Perangkingan alternatif ransel pendakian
7. Penyajian hasil rekomendasi
