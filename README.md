# SPK-AHP-Ransel-Pendakian
Desktop-based Decision Support System for Mountain Hiking Backpack Selection using the Analytical Hierarchy Process (AHP) method. Developed with Java Swing and MySQL.

Teknologi yang digunakan:
1. Java (Java Swing)
2. JDK 11
3. MySQL
4. XAMPP
5. Apache NetBeans
6. Jaspersoft Studio

Application Features:
1. Management of hiking backpack alternative data
2. Management of criteria and sub-criteria data
3. Processing of pairwise comparison matrices
4. Calculation of priority weights using the AHP (Analytic Hierarchy Process) method
5. Consistency testing (Consistency Ratio)
6. Ranking of hiking backpack alternatives
7. Presentation of recommendation results
